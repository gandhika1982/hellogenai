# Weekly Stakeholder Status Report Automation

## Purpose

Prepare a weekly status report for stakeholders covering Git and project
activity in the `hello-genai` project.

## Proposed Schedule

- **Frequency:** Weekly
- **Run time:** Friday at 5:00 PM
- **Time zone:** India Standard Time (IST, UTC+05:30)
- **Reporting period:** Previous Monday through Sunday

## Report Contents

The report should include:

- Commits made during the reporting period
- Files changed during the reporting period
- Current repository status

## Delivery

- **Format:** Ready-to-send email draft
- **Recipient:** `karthik_gandhi@epam.com`
- **Subject:** `hello-genai weekly update — {week ending date}`

This document records the requested configuration. The automation itself has
not been scheduled or enabled.
