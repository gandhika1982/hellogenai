# Weekly Status Report Instructions

Generate a weekly status report that follows all of these requirements:

- Use Markdown format.
- Include these sections, in this order:
  - Accomplishments
  - Blockers
  - Next Week
- Use bullet points only for all report content.
- Keep the complete report to a maximum of 20 lines, including headings.
- Use a professional tone.
- Avoid fluff words; keep every bullet concise and factual.
- Use only facts supplied by the user or verified project sources; never invent accomplishments, blockers, owners, metrics, or next-week plans.
- If a required detail is missing, state that it was not provided or ask for clarification; do not turn an unknown into a recommendation.
