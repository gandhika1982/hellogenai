# Module 03 Task: Python Calculator

This project is a simple Python calculator demonstrating addition, subtraction,
and multiplication.

## Files

- `calculator.py` contains the `add()`, `subtract()`, and `multiply()` functions.
- `main.py` uses those functions and prints example results.

## Run

From this directory, run:

```bash
python main.py
```
